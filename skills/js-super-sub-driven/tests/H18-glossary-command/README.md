**`/glossary` 명시 호출 전용 — `/write-plan` 흐름에서 자동으로 돌지 않음**

## 시나리오 A (기본 호출)

`/glossary docs/features/2026-08-29-잔액-출금/잔액-출금-implementation-plan.md`

**기대:**
- 보조 에이전트 1개를 `model: sonnet` 으로 호출
- 같은 폴더에 `잔액-출금-glossary.md` 생성
- 보고가 `대상 문서 수정: 없음` 으로 끝남
- 대상 문서는 한 글자도 안 바뀜

## 시나리오 B (구현계획서가 아닌 문서)

`/glossary docs/features/2026-08-29-잔액-출금/잔액-출금-tech-design.md`

**기대:** 그대로 진행. 대상 문서 종류로 거절하지 않음. 산출물은 `잔액-출금-glossary.md`.

## 시나리오 C (변경이력이 이미 쌓인 문서)

첫 `[구현계획서-수정]` 항목이 찍힌 계획서를 대상으로 호출.

**기대:** 그대로 진행. 시점 제약 없음. 예전 초안 단계 게이트는 폐지됨.

## 시나리오 D (인자 없이 호출)

`/glossary`

**기대:** 최근 수정된 피처 폴더 후보를 `AskUserQuestion` 으로 제시. 임의로 하나를 골라 진행하지 않음.

## 시나리오 E (/write-plan 흐름)

`/write-plan` 실행.

**기대:** `code-pretty` 만 발화. 용어집 파일 미생성. 승인 게이트 노출물에 용어집 없음.

## 연결 위험

- `/write-plan` 흐름에 용어집 dispatch 부활 → 커맨드 전환 무효
- `commands/glossary.md` 와 같은 이름의 스킬 디렉토리 신설 → 커맨드가 스킬을 가림
- 커맨드에서 `disable-model-invocation: true` 제거 → 대화 중 자동 발동 부활
- 보조 에이전트 없이 메인이 직접 작성 → 코드 탐색이 메인 컨텍스트를 넘침
- 용어집에 `## 변경이력` 꼬리말 추가 → 재생성마다 이력 중복 누적
