# H17 — 소크라테스 단일 경로 시나리오 fixture

`brainstorming` 이 모드를 묻지 않고 단일 경로로 진행하는지, 산출물이 요구 항목 계약을 지키는지 검증. spec: `docs/features/2026-08-15-prd제거-소크라테스고도화/`.

## 시나리오 A — 모드 질문이 뜨지 않는다

- 입력: `/brainstorm 알림 배지` (또는 자연어 "알림 배지 기능 만들자")
- 기대: 진입 라우터 발화 → js-super 풀 트랙 선택 → 프로젝트 탐색 → 피처 이름 확인 → 곧바로 질문 블록 진입
- 실패 신호: "PRD 로 할까요 소크라테스로 할까요" 류 질문, 카테고리 미니질문(외부향/내부도구/수정/인프라), 질문 계획 동의 요청

## 시나리오 B — 산출물이 요구 항목 계약을 지킨다

- 입력: 시나리오 A 에 이어 질문에 답하고 초안 승인까지 진행
- 기대: `<slug>-requirements.md` 에 `## 요구 항목` 섹션 + 항목마다 `FR-N`

```bash
grep -c "^## 요구 항목$" docs/features/*/알림-배지-requirements.md    # 1
grep -c "FR-1" docs/features/*/알림-배지-requirements.md             # 1 이상
grep -c "^> \*\*모드\*\*:" docs/features/*/알림-배지-requirements.md  # 0
```

- 실패 신호: 섹션 이름이 `## 기능 요구` 등으로 나옴, 모드 표기 줄 잔존, FR 번호 부재

## 시나리오 C — 제외 항목이 취합되어 되돌아온다

- 입력: 대화 도중 두 번에 걸쳐 제외 언급 (첫 답변 "소리 알림은 빼고", 세 번째 답변 "웹은 나중에")
- 기대: 문서 작성 전에 두 항목을 모아 보여주고 "더 넣을 게 있는지" 만 질문
- 실패 신호: 빈 상태에서 "범위 밖이 뭔가요" 질문, 앞서 말한 항목 누락

## 시나리오 D — 모르겠다고 하면 사다리를 내려간다

- 입력: 아무 질문에나 "잘 모르겠는데" → 다시 물으면 또 "모르겠어"
- 기대: (1) 더 쉬운 말로 재질문 → (2) 선택지 제시 → (3) 기본값 제안 + 그 기본값의 전제 명시 + 진행 여부만 확인
- 실패 신호: 첫 응답에서 바로 기본값 결정, 사용자가 모른다고 한 채로 대화 정지

## 시나리오 E — 옛 형식 문서도 읽힌다 (하위호환)

- 입력: PRD 형식 기존 문서(예: `docs/features/2026-08-09-워크트리-재분기/`)를 `/tech-design` 에 투입
- 기대: 형식 구분 안내 없이 `FR-N` 을 읽어 §2 매핑 생성
- 실패 신호: "PRD 모드 입력으로 감지했습니다" 류 발화, 요구 항목 매핑 0건

## 보조 검증

- 질문 개수 상한 없음 — 커버 목록 5가지가 채워지면 종료. 가벼운 사안은 2~3개로 끝나야 함
- 대안 제시 시 고정 비교축 3개(무엇이 달라지나 / 무엇을 포기하나 / 되돌리는 비용) + 추천 먼저 + 추천안이 깨지는 조건 1개
- 승인은 초안 전체 1회. 섹션별 승인으로 회귀하면 실패
- 보존 문자열: `--no-ask` 섹션 제목 / `Advise: run /og-brainstorm` / `visual-companion.md` 경로가 그대로일 것
