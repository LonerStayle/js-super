비용 하한 = 72 × $0.605 = **$43.6**. 이건 "reply with exactly: ok" 수준 trivial 응답 1턴의 컨텍스트 세금만 곱한 값이다. 실제로는 멀티턴(정식 트랙은 최소 3회 AskUserQuestion 응답)과 wave-parallel 서브에이전트 비용이 얹히므로 **실제 총비용은 이 값의 수 배**다 (배수는 추측 — 실측 근거 없음).

4-way 병렬로 돌리면 상한 ≈ 2시간 51분. 단 `--plugin-dir` additive 문제와 HOME 미격리 때문에 **병렬 실행은 현재 구조에서 서로를 오염시킨다** (worktree/git/`~/.claude/skills` 를 건드리는 대상이 다수).

### 판정: **"로컬 수동 실행" 과 양립 불가**

근거 3가지:

1. **대기 시간**. 스킬 1개를 고칠 때마다 최악 11시간, 낙관적 추측치로도 3~4시간. "고치고 돌려보고 다시 고친다" 는 루프가 성립하지 않는다.
2. **비용**. 1회 전수 $43.6(하한)을 하루 몇 번 반복하면 스킬 수정 세션 자체보다 eval 이 비싸진다.
3. **격리 부재**. 72 런 중 상당수가 실제 파일 삭제·git 조작을 한다(§4). 격리 샌드박스 없이 로컬에서 전수를 돌리는 것은 **저장소와 `~/.claude/` 를 망가뜨리는 행위**다. 격리를 붙이면 셋업/티어다운 시간이 런당 추가된다.
